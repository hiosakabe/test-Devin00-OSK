# シーケンスデータの学習・推論モデル

このリポジトリでは、与えられたシーケンスデータを学習し、次の文字を予測するディープラーニングモデルを実装しています。

## データセット

学習に使用したシーケンスデータ:
```
A→B→C
A→B
A→B→C→D→E→F
A→B→C→D→E→F→G→H→I
A→B→C→D→E→F→G→H→I
A→B→C→D
A→B→C
```

推論例:
```
A→B→?
```

## モデルについて

このモデルは以下の特徴を持っています：

1. PyTorchを使用したLSTM（Long Short-Term Memory）ネットワーク
2. 文字をベクトル表現に変換する埋め込み層
3. シーケンスの次の文字を予測する全結合層

## 使用方法

### 必要なライブラリ

```
pip install torch numpy
```

### 学習と推論の実行

```
python sequence_model.py
```

このスクリプトを実行すると、モデルの学習が行われ、学習後に「A→B→?」の推論結果が表示されます。

### モデルの保存と読み込み

学習済みモデルは `sequence_model.pth` として保存されます。

## 結果

モデルは与えられたシーケンスデータから学習し、「A→B→?」の次に来る可能性が高い文字とその確率を出力します。
